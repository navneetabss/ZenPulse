# ZenPulse
Healthcare Management System (Hospital ERP) built using MERN Stack


🌟 ZenPulse Hospital Management System

  A Modern Hospital Management System built with HTML, CSS, and
  JavaScript

------------------------------------------------------------------------

🎯 Project Overview

ZenPulse is a responsive front-end Hospital Management System designed
for academic demonstrations and portfolio projects. It provides an
intuitive interface for managing patients, doctors, appointments,
billing, pharmacy, reports, and administration.

------------------------------------------------------------------------

✨ Features

-   👨‍⚕️ Doctor Management
-   🧑‍🤝‍🧑 Patient Management
-   📅 Appointment Scheduling
-   💳 Billing Dashboard
-   💊 Pharmacy Module
-   📊 Reports & Analytics
-   🔐 Login UI
-   🌙 Dark Mode
-   📱 Responsive Design
-   💾 Local Storage Support

------------------------------------------------------------------------

🛠️ Technologies

-   🌐 HTML5
-   🎨 CSS3
-   ⚡ JavaScript
-   🅱️ Bootstrap 5
-   📈 Chart.js
-   ⭐ Font Awesome

🚀 Getting Started

1.  Download the project.
2.  Open the folder in VS Code.
3.  Launch index.html in your browser.
4.  Explore the modules.
