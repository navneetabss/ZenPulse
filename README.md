## 🎯 Overview

**ZenPulse** is a responsive, front-end Hospital Management System designed for academic demonstration and portfolio use. It offers a clean, intuitive interface for managing every core hospital function — patients, doctors, appointments, billing, pharmacy, reports, and administration — all from a single, unified dashboard.

Built with performance and clarity in mind, ZenPulse simulates a real-world hospital ERP experience while remaining lightweight and easy to run in any browser.

## 🚀 Getting Started

```bash
# 1. Clone or download the project
git clone <repo-url>

# 2. Open the folder in VS Code
cd ZenPulse
code .

# 3. Launch in your browser
# Right-click index.html → "Open with Live Server"
# (or simply double-click index.html)
```

No build steps, no dependencies to install — just open and explore.
